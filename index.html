About the model

This is an exploratory metaphor for interaction, built from Maya’s Python simulation. It is a simplified dynamical system; its behavior can open questions about ecological agency and trajectories over time. It does not establish how people behave.

Every active site contributes attraction: pull = C × weight / (distance²)^P, directed towards that site. Distance squared is floored at 0.01. Velocity is updated from the total acceleration, multiplied by the damping factor, then used to update position with semi-implicit Euler integration. DT = 0.1, K = 0; defaults: C = 10, P = 0.3, damping = 0.9.

In the original mode, a site deactivates before the next force calculation when the agent enters its radius. The radius equals its weight. The browser version keeps these rules, adds controls, and stops after 5,000 units of model time. The viewport follows points outside the initial 0–100 field; there are no artificial walls. Parameter changes restart the trajectory for comparison. Each student runs an independent experiment on their own device.
