# Interaction in Fourth-wave HCI

A classroom experiment for CS 705, exploring how a trajectory emerges through relations with its environment.

## Try the simulation

**[Open the interactive simulation →](https://71y.github.io/becoming-simulation/)**

Click **Run** to get started. Move the interaction sites, change their salience, or adjust the dynamics to see how the trajectory changes.

## Python code

The original simulation is in **[python simulation.py](python%20simulation.py)**.

The website runs directly in your browser; the Python file contains the original model.
